# PrediMate Roadmap: Common vs. Personalized

The PrediMate roadmap is structured with common foundational phases applicable to all product versions (CORE, INDUSTRIAL, INFRA, SENTINEL, CONNECT), followed by personalized phases that cater to each version's specific needs.

## Common Steps for All Product Versions (Phases 1-6)

These phases establish the core functionality and infrastructure of PrediMate.

**Phase 1: Requirements & Prototype Setup**

* Stakeholder & Data Discovery
* Synthetic Data & Simulator
* Ingestion Pipeline PoC
* Basic Anomaly Detection Demo
* Dashboard Mockup

**Phase 2: Core Agentic AI Build**

* Architecture & Orchestrator
* Anomaly Detection Models
* Root-Cause Analysis (RCA) Module
* Embedding & Vector Store
* LLM-Driven Recommendations
* Audit Trail & Explainability

**Phase 3: Integration & API-First**

* PLC/SCADA Connectors
* ERP & CMMS Adapters
* API Gateway & Auth
* SDKs & CLI
* Self-Serve Sandbox

**Phase 4: Metering, Billing & Tiering**

* Usage Event Stream
* Billing Pipeline
* Pricing & Feature Flags

**Phase 5: Stealth Beta & Analytics**

* Multi-Tenant Environments
* Telemetry & Monitoring
* Feedback & A/B Testing
* Security Hardening (Pilot)

**Phase 6: Production Launch & Scaling**

* Infra-as-Code
* CI/CD & Deployment
* Auto-Scaling & Resilience
* CDN & Edge Caching
* SRE & Runbooks

These common steps ensure a solid foundation across all PrediMate versions, with consistent core AI capabilities, infrastructure, and integrations.

## Personalized Steps Based on Product Version (Phases 7-8)

Starting from Phase 7, the roadmap diverges to address the unique requirements of each product version.

**Phase 7: Ecosystem & Marketplace (Months 8–12)**

* **Plugin Framework:**
    * Version-specific plugins for industry tools and protocols (e.g., INDUSTRIAL: machinery monitoring, CONNECT: IoT devices).
* **Marketplace Backend:**
    * Customized marketplaces tailored to each vertical (e.g., SENTINEL: security plugins, INDUSTRIAL: machine diagnostics).
* **Referral & Partner Engine:**
    * Partnerships aligned with each version's target market (e.g., INFRA: infrastructure providers, SENTINEL: security vendors).
* **Partner Portal:**
    * Version-specific tools and resources for partners (e.g., INDUSTRIAL: plant operators, CONNECT: service providers).

**Phase 8: Security, Compliance & Expansion (Months 12+)**

* **Compliance Certification:**
    * Industry-specific certifications (e.g., INDUSTRIAL: ISO 9001, IEC 61508; SENTINEL: SOC 2).
* **Security Hardening:**
    * Advanced security features tailored to each version's risk profile (e.g., SENTINEL: intrusion detection, INFRA: data protection).
* **Patent & IP Protection:**
    * Version-specific patents for unique innovations (e.g., INDUSTRIAL: predictive maintenance models, SENTINEL: real-time anomaly detection).
* **New Vertical Generator:**
    * Tools for creating new verticals relevant to each product version (e.g., INDUSTRIAL: manufacturing, oil and gas; SENTINEL: cybersecurity).

## Where Does the Roadmap Start to Personalize?

The roadmap begins to personalize in **Phase 7: Ecosystem & Marketplace**, focusing on:

* Integrating with partner ecosystems.
* Defining specific plugins.
* Customizing partner portals.
* Tailoring compliance and security features.

**Key Points:**

* **CORE:** Establishes the foundational infrastructure, AI, and integrations.
* **INDUSTRIAL, INFRA, SENTINEL, CONNECT:** Leverage CORE capabilities and add vertical-specific functionalities.
* **Phases 7 & 8:** Shift towards each version's unique value proposition and market fit.
